# Harrow Court Web Edition

此目錄是可直接部署的獨立靜態網站，不依賴 Ren'Py、Node.js、資料庫或 Blog Theme。

- `index.html`：遊戲官方網站首頁
- `game/index.html`：瀏覽器遊戲本體
- `data/story-data.js`：由原始 `game/story/day01.rpy`～`day07.rpy` 產生的完整劇情資料
- `assets/`：網站與遊戲共用圖片、字型及 BGM

直接開啟 `index.html` 即可測試。部署時請完整上傳此目錄內容，路徑可位於網站根目錄或 `/games/harrow-court/` 等子目錄。

背景音樂請放在：`assets/audio/bgm/main-theme.mp3`。
